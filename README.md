# About

This repository contains the source code for my personal portfolio website.

The portfolio showcases my work in **software engineering, full-stack web development, machine learning, and data analytics** through projects, technical skills, education, and achievements.

Designed with a focus on **performance, responsiveness, accessibility, and clean UI/UX**, the website is intentionally built using **pure HTML, CSS, and JavaScript** to deliver a lightweight, fast, and dependency-free experience.

# Getting Started

Clone the repository

```bash
git clone https://github.com/geekazfaar/Portfolio.git
```

Navigate to the project directory

```bash
cd Portfolio
```

Run a local development server

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```

Open your browser and visit

```
http://localhost:8000
```
